# Echo360 Visual System

## Direction

Echo360 inherits the product discipline of SFP — dense information without visual noise, clear hierarchy, consistent spacing, compact controls, strong cards and status-first UI — but does **not** copy its financial aesthetic.

The Echo360 identity is **dark-tech / Xbox / near-future console OS**.

## Core principles

1. **Black is the canvas** — backgrounds stay near-black, not generic Material gray.
2. **Green is signal, not wallpaper** — bright Xbox/neon greens mark focus, health, selection and primary actions.
3. **Depth without glass abuse** — layered dark surfaces, thin borders and restrained glow replace heavy shadows.
4. **Technical, still playable** — protocol/diagnostic language can exist, but the player-facing hierarchy always wins.
5. **Compact precision** — spacing and control density follow the same disciplined rhythm used by SFP.
6. **Console OS feel** — short uppercase eyebrows, subsystem codes (`LB`, `TX`, `XB`), status pills and command-like labels create continuity across modules.
7. **No cyberpunk clutter** — no random scanlines, giant neon borders, excessive gradients or decorative telemetry that competes with content.

## UI grammar

- 18px-equivalent panel radius, less rounded than the early prototype.
- Thin technical borders instead of floating Material cards.
- Primary CTA = neon green on black text.
- Secondary CTA = raised black/green surface.
- Navigation uses two-letter subsystem glyphs and a soft green active indicator.
- Hero areas may use subtle radial/horizontal green illumination.
- Status uses pills with a small signal dot.

## Relationship to SFP

Keep:
- hierarchy;
- compact information density;
- spacing rhythm;
- strong primary/secondary text contrast;
- panel/list consistency;
- bottom navigation discipline on mobile.

Change:
- blue/teal financial palette -> Xbox green/black;
- dashboard/business tone -> console/launcher tone;
- conventional cards -> technical panels;
- financial metrics -> console status, sessions, game state and actions.

This document is the source of truth for future EchoHome, EchoLibrary, EchoTransfer, EchoDoctor and EchoCore UI work.
