# Versioning

Echo360 uses semantic-style product versions while the app is pre-1.0.

- `0.1.x` — native Android foundation and connectivity
- `0.2.x` — EchoTransfer native parity
- `0.3.x` — EchoHome / EchoLibrary
- `0.4.x` — EchoDoctor / Remote / integrity
- `1.0.0` — stable native app with the legacy Companion no longer required for normal use

Release candidates use suffixes such as `-rc1` when hardware validation is still pending.
