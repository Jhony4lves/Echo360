# Echo360 Changelog

## 0.4.0-rc1
- Release candidate para bateria de testes em hardware.
- Preferências do EchoTransfer persistidas.
- ID de análise com validade de 15 minutos.
- Mudança de origem/destino/modo invalida a análise.
- Verificação pós-upload por tamanho remoto.
- Histórico persistente das transferências.
- Avisos para planos suspeitos.
- Mantém seletor gráfico, FTPdll ativo, Aurora passiva, QUIT e sessão reutilizada.
- Nenhum comando de exclusão remota.
