# Echo360 Companion v0.4.0-rc1

RC para testes concentrados quando o Xbox estiver disponível.

## Novidades
- últimas pastas/modo ficam salvos;
- análise expira em 15 minutos;
- mudar origem/destino/modo exige nova análise;
- upload concluído é verificado por SIZE no Xbox;
- histórico persistente das últimas transferências;
- avisos para planos de transferência suspeitos.

## Precisa de teste no Xbox
- SIZE pós-upload em Aurora e FTPdll;
- fila longa na Aurora;
- failover Auto ao abrir jogo;
- throughput;
- pausa/cancelamento em arquivos grandes.

## Segurança
Nenhum DELE ou RMD.
